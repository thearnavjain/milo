## Host observations

The host has Windows x64, Visual Studio Community 18, WebView2 Evergreen, Rust stable MSVC 1.99.1, rustfmt, and Windows SDK 10.0.26100. WMI identifies Windows 11 Home Single Language, version `10.0.26300`, build `26300`; one primary display reports 1536×864, while WMI reports 120 horizontal DPI. These identify the build host but do not establish MILO's runtime scale factor. The loose release executable launched on 2026-11-04. A later `corepack pnpm tauri dev` rebuild and runtime launch also succeeded; the current Rust test executable ran successfully. Earlier development and Rust test executables were denied by Windows Application Control with OS error 4551. Security controls were not changed or bypassed. Tauri, Rust, and frontend compilation pass independently of complete runtime validation. See [SHELL_VALIDATION.md](SHELL_VALIDATION.md) for observed results and the remaining matrix.
